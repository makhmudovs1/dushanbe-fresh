## Обязательные Незавершённые Условия

1. **Независимая копия:** вне обоих VPS пока отсутствует. Нужна проверка фактического
   восстановления из этой копии, не только письмо о наличии weekly backup.
2. **Новый публичный сертификат:** старый ключ не копируется. A-записи ещё старые;
   выпуск до cutover требует временных DNS-01 TXT через Navju либо отдельно
   разрешённой HTTP-01 проверки старого сайта. Попытка изменить public challenge
   и коротко перезапустить старый Web была заблокирована автоматической проверкой
   разрешений; действие не выполнено, отдельно запрошено согласие/альтернатива.
   Новый ACME client и standby proxy подготовлены, не объявляются уже работающим
   HTTPS. `start-standby-proxy.py` отказывается запускаться без нового сертификата.
   Альтернатива без изменения старого хоста:
   [DNS-01 manual в официальной документации Lego](https://go-acme.github.io/lego/dns/manual/index.html).
3. **Минимальная защита хоста:** владелец должен выполнить sudo helper
   `harden-production-host.py --stage`. Он сохраняет порт22, разрешает22/80/443,
   проверяет подтверждённый ключ, включает IPv4/IPv6 firewall, отключает root и
   password SSH только с таймером отката. Во втором локальном терминале нужен
   новый вход тем же ключом; `KEEP` принимается лишь после его записи в журнале.
   Без KEEP откат через пять минут. Эти изменения ещё не объявлены применёнными.
4. **Freeze/final sync:** только после первых условий остановить все старые
   писатели, проверить read-only/отсутствие пишущих соединений и повторить export
   в новый quarantine. Сверить полные бизнес-fingerprint и связанные фото. Не
   перезаписывать сегодняшнюю initial-копию вслепую. Текущий importer предназначен
   для пустого target и проверенного среза без заказов: при появлении покупателей,
   адресов или заказов останавливается, а не пропускает их. Перед финальным импортом
   расширить allowlist/проверки по реально обнаруженным данным либо доказать
   неизменность исходного среза после freeze. Не выполнять seed/TRUNCATE/reset.
5. **Одно финальное подтверждение владельца** непосредственно перед A/AAAA.
   Пока его не запрашивали: условия выше ещё не закрыты.
