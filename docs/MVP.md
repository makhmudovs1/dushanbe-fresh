# MVP

Строгие границы первого MVP для сервиса доставки свежих продуктов с рынков
Душанбе. Этот документ определяет, что делаем в первой версии, а что явно
откладываем.

## Реализованный операционный цикл

Заказ клиента → окно доставки → подтверждение администратором → одна волна
на окно → агрегированный список с предпочтениями по качеству → закупка на рынке
→ ручное распределение фактических количеств по заказам → курьер → доставка
→ отметка получения наличных.

Операционные страницы: `/admin/orders`, `/admin/orders/:id`,
`/admin/delivery-waves`, `/admin/delivery-waves/:id`. Сборщик и курьер назначаются
из пользователей соответствующих ролей. Отдельное приложение им не требуется.
Сотрудники входят по email и паролю. Access JWT живёт 10 минут, refresh token
ротируется и хранится в БД только как SHA-256 hash; браузер получает его через
httpOnly `SameSite=Lax` cookie (`Secure` в production). Администратор управляет
каталогом, заказами и назначениями; сборщик видит только назначенные волны и
вносит закупку/фактические количества; курьер видит только назначенные доставки
без закупочных цен и может отмечать доставку и наличные.

Стоимость закупки отделена от цены клиенту. Итоги закупки и заказов считает
backend через Decimal. Показатель «Валовая маржа по товарам» исключает доставку,
сервисные сборы и операционные расходы и не является чистой прибылью.

## A. Customer MVP

- Каталог товаров.
- Категории товаров.
- Карточка товара.
- Адаптивный web-интерфейс для мобильных и desktop-экранов.
- Корзина.
- Выбор предпочтения по качеству для товаров, где это применимо.
- Политика замены для заказа:
  - заменить похожим;
  - связаться со мной;
  - удалить товар.
- Guest checkout без обязательного SMS OTP.
- Имя, телефон и адрес доставки при checkout.
- Сохранение snapshot адреса в заказе.
- Выбор 2-часового окна доставки.
- Создание заказа.
- Базовый статус заказа.
- История заказов, если она не усложняет MVP существенно.

## B. Admin MVP

- Управление категориями.
- Управление товарами.
- Управление продажной ценой.
- Изменение доступности товара на сегодня.
- Изменение текущей закупочной цены, если она используется.
- Управление delivery slots.
- Просмотр заказов.
- Изменение статусов заказа.
- Назначение сборщика.
- Назначение курьера / Porter.
- Picking list по delivery wave.
- Просмотр агрегированных товаров по волне доставки.
- Ввод финального количества товара в заказе.
- Ввод фактической закупочной цены по товару в delivery wave.
- Ввод реально купленного количества по товару в delivery wave.
- Замена товара.
- Удаление отсутствующего товара из заказа.
- Изменение payment status.
- Базовые метрики дня:
  - заказы за день;
  - заказы по статусам;
  - сумма заказов;
  - загрузка окон доставки.

## C. Не входит в MVP

- Онлайн-оплата.
- Real-time отслеживание курьера.
- Автоматическая оптимизация маршрутов.
- Оптимизация работы сразу с несколькими рынками.
- Складская система.
- Dark store.
- Нативное мобильное приложение.
- AI.
- Marketplace продавцов.
- Программа лояльности.
- Промокоды.
- Мясо.
- Заморозка.
- Сложная холодовая цепь.
- Микросервисы.
- Redis, пока не появится реальная необходимость.
