# Финальная доработка витрины, 18 октября 2026

## Изменения

- Только фирменный тёмно-зелёный для покупок и активных состояний; жёлтые кнопки,
  hover счётчика и badge корзины убраны. Карточки без повторяющегося наличия;
  прежняя фильтрация доступности, фото, настоящие скидки и качество сохранены.
- В хедере поиск ограничен 600 px, корзина без тяжёлого фона, её счётчик выше
  значка и не пересекает его. Избранное убрано только из хедера по уточнению
  пользователя. На товарах и в боковом меню оно остаётся.
- Главная начинается тематическими категориями, в конце — до 8 товаров.
  Корневые овощи и зелень объединяются визуально, без смены ID/связей.
  Остальные разделы и порядок берутся из БД. Пустые/невидимые ветки исключены;
  несуществующие подкатегории и демотовары не создаются.
  Одиночные разделы на desktop располагаются компактным рядом, сохраняя
  последовательность данных; на mobile идут друг за другом.
- Плитки имеют скругление 16–18 px, реальные фотографии из предыдущих архивов
  и независимый контрастный HTML-текст RU/TJ. Большие баннеры сохранены в assets.
- На странице категории — локализованные хлебные крошки, реальное дерево
  навигации, компактный заголовок и единая товарная сетка. Поиск только в хедере.
  Анимация 180 мс, reduced motion сохранён.
