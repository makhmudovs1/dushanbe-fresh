# Физический iPhone — чек-лист 0.4.0 (5)

Для локальной установки нужен подписанный device `.app` или IPA с входящим в provisioning устройством. Сборку Simulator используйте только на Simulator. [Манифест build 5](mobile-rc-20261118/artifacts.json) содержит SHA-256 архива `iphoneos`, а [инструкция по сборке](MOBILE_RC_20261118.md) описывает локальный Release с preview ID.

## Установка и запуск

1. Подтвердите Apple Developer Team и доступность preview App ID `tj.dushanbefresh.app.preview`. Для внутреннего локального теста зарегистрируйте тестовые устройства в этой команде. Установите действующий сертификат и соответствующий профиль через Xcode. Подключите телефон, доверьте Mac, включите Developer Mode для development build.
2. Соберите Release под нужное окружение. В **Window → Devices and Simulators** выберите зарегистрированный iPhone и установите подписанный `.app`. Сверьте идентификатор, `CFBundleShortVersionString` и `CFBundleVersion` с манифестом. Для TestFlight после отдельного разрешения потребуется распределительная подпись, App Store Connect record и первый принятый архив.
3. Для сценария покупателя выберите выделенный тестовый iPhone и изолированный API с тестовым OTP. Адрес `127.0.0.1` на iPhone указывает на сам телефон. Для физического checkout нужен отдельный `integration` Release с API на частном адресе RFC1918, HTTPS с доверенным сертификатом для адреса стенда и проверкой `runtimeId` выделенного тестового API. В текущих EAS профилях отправка выключена. На production preview проверяйте просмотр и обязательный вход без запроса реальных SMS.

## Сценарии на устройстве

- На маленьком и большом iPhone сравните 11 публичных состояний с референсами build 5. Проверьте клавиатуру поиска, телефона, OTP и адреса, жест назад, закрытие sheets, safe areas, увеличенный размер текста и возврат после фонового режима. На iPad проверьте те же состояния и размеры окна.
- На тестовом окружении выполните вход, выгрузку процесса, восстановление Keychain после запуска, WEB/MOBILE корзину, проверку стоимости и одно подтверждение. Покажите статусы заказа после назначения курьера. Выполните выход и повторный запуск, затем убедитесь, что открываются гостевые экраны.
- Проверьте Apple Maps, отказ и повторную выдачу доступа к местоположению, переключение точности, выбор точки, поиск, обратное геокодирование и сохранение координат. Проверьте экран при включённой системе Reduce Motion. Потеря связи при проверке суммы должна позволить безопасно повторить чтение после восстановления сети.

## Журнал дефекта

Укажите SHA, версию, bundle ID, модель, версию iOS, язык, время, сеть, шаги, фактический и ожидаемый результат. Экспортируйте `.ips` из **Xcode → Devices and Simulators → View Device Logs** или с телефона через **Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики**. Для символикации приложите UUID сборки и сохраните соответствующий dSYM из `.xcarchive`. Очистите вложения от номеров телефонов, OTP, токенов, URL отслеживания, адресов и ключей.
