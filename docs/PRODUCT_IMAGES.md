Это иллюстративные фотографии обычных продуктов, не фотографии нашей конкретной партии.
Исходники скачаны, визуально проверены и обработаны существующим `MediaService`:
WebP, до 1600 px, без EXIF. Файлы отдаются нашим `/api/v1/media/<uuid>.webp`,
без hotlink. В production они лежат в постоянном `PRODUCT_IMAGES_DIR`, вне Git.
Исходные URL файлов:

- https://upload.wikimedia.org/wikipedia/commons/8/89/Potato.JPG
- https://upload.wikimedia.org/wikipedia/commons/c/c8/Carrots.jpg

Контрольные суммы и назначенные UUID сохраняются в manifest рядом с резервной
копией БД перед загрузкой. Меняются только `image_url` выбранных товаров;
загруженные администратором фотографии не перезаписываются.

Для остальных товаров пока оставлен единый брендовый placeholder. Это не полный
фотокаталог: подходящие фотографии для всех позиций ещё не подобраны.
Для Paykar подтверждения разрешения на переиспользование не найдено, файлы не копировались.
Наличие изображения в поиске или в Wikimedia не заменяет проверку лицензии конкретного файла.
Фото с CC BY/CC BY-SA потребуют публичной атрибуции и соблюдения условий лицензии;
в этой поставке они не используются. Администратор может заменить фото обычной загрузкой.
