## Хранение и обработка

Это иллюстрации вида продукта, а не фотографии конкретной продаваемой партии.
Источники — Wikimedia Commons. Магазины служат только визуальным ориентиром.
Файлы скачиваются, приводятся к квадратному полотну с сохранением пропорций и
содержимого, затем проходят существующий `MediaService`: WebP, максимум 1600 px,
без EXIF. Белое поле добавляется для сохранения продукта целиком; фон не дорисовывается.

Файлы отдаются нашим `/api/v1/media/<uuid>.webp`, без hotlink. В production лежат в
постоянном `PRODUCT_IMAGES_DIR`, вне Git. URL источника, автор, лицензия и SHA-256
сохраняются в manifest рядом с backup БД. В PostgreSQL меняется только `image_url`
и служебное `updated_at` выбранных товаров. Все остальные поля и таблицы сверяются.

Обработанные CC BY-SA изображения распространяются по той же версии лицензии.
Лицензии фотографий не распространяются на код сайта. На `/photo-credits` доступны
источники, авторы, лицензии и сами обработанные файлы. Администратор может заменить
фотографию обычной загрузкой; уже загруженные им фото массовый импорт не перезаписывает.
