# О проекте

Сервис доставки свежих продуктов с рынков Душанбе.

## Проблема

Люди хотят покупать свежие продукты с рынка, но поездка на рынок
занимает время: дорога, выбор продуктов, перенос пакетов, обратная дорога.

Мы берём эту работу на себя.

## Как работает сервис

1. Клиент выбирает продукты на сайте.
2. Выбирает окно доставки.
3. Заказы группируются в волны.
4. Сборщик на рынке закупает сразу товары для нескольких клиентов.
5. Продукты разделяются по заказам.
6. Курьер забирает несколько заказов.
7. Заказы развозятся клиентам.

Пока НЕ делаем:

- нативное мобильное приложение

## Разновидности и качество

Каждая продаваемая разновидность — отдельный `Product`: например,
«Картофель белый» и «Картофель красный» в общей категории «Овощи».
У неё собственные название RU/TJ, фотографии, цена, единица, минимум,
шаг покупки и доступность. Новую систему SKU не вводим.

Выбора предпочтений «спелый», «твёрдый» и подобных больше нет.
Исторические предпочтения и снимки заказов сохраняются только для чтения.
Старые позиции корзины требуют явного удаления и повторного выбора товара,
без автоматического объединения или замены разновидности.

Если качество плохое — ответственность несёт платформа.

## Замены

Для каждого заказа пользователь выбирает:
- заменить похожим
- связаться со мной
- удалить товар

## Вес

Продукты на вес продаются с приблизительным весом.
Финальный вес фиксируется при сборке.

## Логистика

Не используем модель один заказ = одна поездка.

Заказы группируются в волны доставки.

Пример:
10:00–12:00
14:00–16:00
18:00–20:00

Сборщик объединяет количество одного `Product.id` по заказам волны.
Разные разновидности не объединяются. Фактический вес фиксируется отдельно
для каждой позиции заказа; излишек закупки не распределяется автоматически.

## Монетизация — пока гипотеза

- минимальный заказ: 100–150 сомони
- доставка: 15–25 сомони
- наценка: около 10%

Все значения должны быть вынесены в конфигурацию.
