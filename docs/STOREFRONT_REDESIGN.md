# Редизайн витрины, 18 октября 2026

Это отчёт о первом этапе. Актуальная компоновка, иерархия категорий, избранное,
живой поиск и новые проверки описаны в [STOREFRONT_V2.md](STOREFRONT_V2.md).

## Область изменений

Главная: постоянный каталог слева на desktop, два баннера в пропорции 2.3:1,
фотокарточки реальных категорий, прежние товарные карточки в сетке 4/3/2.
На mobile категории доступны в выдвижном диалоге с фокусом, Escape и ссылкой
на корзину. Главная не ждёт API для показа хедера, баннеров и заголовков;
категории и товары загружаются независимо через Suspense. Чтение категорий
мемоизировано только внутри серверного запроса, не между посетителями.

Хедер: прежний логотип, настоящий поиск, Душанбе, активный гостевой заказ,
корзина со счётчиком, RU/TJ. Последняя сохранённая ссылка остаётся в footer
даже после завершения заказа. GPS и новые адресные функции не добавлены.
На desktop главной и каталога кнопка открытия каталога убрана, поскольку меню
уже слева. На остальных маршрутах остаётся компактный доступ к каталогу.

Карточки товаров, quantity stepper, выбор качества, галерея, реальные скидки,
localStorage и правила цены сохранены. Footer, checkout и операционные экраны
не переделаны. Стили новой сетки ограничены витриной; хедер общий.

## Миграция и данные

Добавлены nullable `categories.image_url` и `categories.is_visible NOT NULL DEFAULT true`.
Нет удаления, изменения связей, переименования таблиц и обновления товаров.
Скрытая категория остаётся доступной администратору; её товары не меняются,
не удаляются и доступны по прежним правилам. Старый `is_active` не подменяется.

Миграция применена к отдельной локальной копии БД
`dushanbe_fresh_home_test_20261018`. Повторный `db:deploy` подтвердил отсутствие
ожидающих миграций. Снимки 23 защищённых таблиц до/после совпали, 16 категорий
получили `image_url=null`, `is_visible=true`. Также проверена локальная dev-БД
после backup `/tmp/df-home-local-dev-20261018.dump`: 14 категорий и те же
защищённые таблицы сохранены. К production БД не подключались, production не изменён.
Для локального preview недостающие файлы уже существующих товарных фото были
скачаны чтением публичных media URL; импорт или изменение production не выполнялись.

## Перед будущим production deployment

Автоматического деплоя в рамках задачи нет. Требуется отдельное подтверждение.
Дальше: backup PostgreSQL, проверить постоянное файловое хранилище, применить
`db:generate`/`db:deploy`, собрать и запустить текущим существующим процессом.
Seed/reset не нужны. Новое приложение запускается только после миграции.

После согласованного деплоя проверить реальные фото/ссылки, RU/TJ, корзину,
checkout без создания заказа, активную гостевую ссылку и загрузку фото категории
под production admin. Проверку на физических телефонах Safari/Android и
редакторскую вычитку таджикских текстов пока нужно выполнить отдельно.
